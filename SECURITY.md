# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub Private Vulnerability Reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the affected version, a description of the problem, and steps to reproduce it if you have them.

We aim to acknowledge a report within 7 days.
